## 4. Requisiti Architetturali di Salvaguardia

1. **Nessun reindirizzamento fragile:** Tutte le rotte devono rispondere con codice `200 OK` diretto sia alla richiesta dell'URL pulito (`/csa-vol1-bonus-8f2e91b7d4a6`), sia alla richiesta con `.html`, sia alla richiesta con trailing slash (`/`).
2. **Supporto Doppio Host:**
   - **GitHub Pages:** Sfrutta sia la presenza del file `.html` alla radice sia la sottocartella con `index.html`, coadiuvata dal dispatcher `404.html` per intercettare qualsiasi discrepanza di routing.
   - **Vercel:** Mantiene attive le regole di rewrite in `vercel.json` (`cleanUrls: true` e mapping espliciti).
3. **Integrità degli Asset Dipendenti:**
   - I file di stile `style.css` e i file script `books.js` e `script.js` richiamati dalle pagine QR continuano a fornire piena compatibilità all'indietro.
   - I file multimediali audio `.wav`, video `.mp4` e i documenti `.pdf` in `assets/construction-site-adventures/` e `assets/einstein/` rimangono intatti nei loro percorsi.
4. **Collaudo Continuo:**
   - `test-qr-routes.js` viene eseguito ad ogni build e verifica l'esistenza e la non-vacuità di ogni singolo file e asset permanente.
